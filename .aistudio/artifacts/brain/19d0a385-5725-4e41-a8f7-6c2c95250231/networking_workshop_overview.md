## 🛠️ The 6 Hands-On Practical Stations

1. **RJ45 Cabling & Crimping Drill**:
   - Master T568B color codes, cable stripping, punch-down keystones, ratchet crimping, and live digital LED continuity tester verification.
   - *Takeaway: Every participant crimps and takes home their custom-built, verified Cat6 patch cable.*

2. **Cisco Switch CLI & VLAN Isolation**:
   - Console rollover access via serial cables, navigating IOS CLI commands, setting up departmental VLANs, 802.1Q trunking, and isolating corporate broadcast domains.

3. **Enterprise Routers & Dynamic OSPF Routing**:
   - Bootstrapping enterprise routers, IP scheme and subnet calculation, default routing, and live inter-VLAN routing across distinct subnets.

4. **Hardware Firewalls & Security Rules**:
   - Deploying physical firewall appliances, setting stateful Access Control Lists (ACLs), NAT/PAT gateway mapping, and switch port security locks.

5. **Wireshark Live Packet Sniffing & Troubleshooting**:
   - Capturing real Ethernet frames, decoding TCP 3-way handshakes, DNS queries, DHCP DORA cycles, and diagnosing simulated link drops and IP collisions.

6. **Behind-The-Scenes Jaya TV Broadcast Facility Tour**:
   - Guided tour of active Master Control Room (MCR), Production Control Room (PCR), server rack farm, and live video-over-IP encoding pipelines powering 24/7 on-air television.
